Hướng Dẫn Thêm Quà Tặng Mới & Ghép File Giọng Đọc:
  1. Mở file js/prizes-config.js trong thư mục mã nguồn.
  2. Thêm 1 block sản phẩm mới với tên, hình ảnh (assets/prizes/...) và file ghi âm MC (assets/voices/...).
  3. Lưu file và tải lại trang: Giao diện sân khấu, tab điều hướng, số lượng quà, hiệu ứng và giọng đọc sẽ tự động đồng bộ 100% mà không cần sửa code HTML!
